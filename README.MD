#### Nearly all custom textures for every block within Supplementaries

> <small> Party supplys such as presents, pignatia ect... Are excluded </small>

Goal behind this pack is to not break immersion when I use ashen in modded Minecraft modpacks! With a long term goal of having compatability to most commonly used mods.

Since that's the Main Target for this pack is Supplementaries it's in the name but this also bundles supp^2 and Amendments, as Supplementaries tend to have lots of overlap between them.

![Compatibility](https://i.imgur.com/MwVLhEd.png)

Created on Neo-forge 1.21.1 if any issues are encountered in older versions provide a issue report, but don't expect a swift reply or fixes. But I'll do my best!

### Mod Configurations
If using the Amendments part of this pack Turn off disc Rotations.
- `Amendments > Client > Jukebox > Disc Spin`

Turning off Pixel Consistent Signs in Amendments if you prefer the classic sign textures
- `Amendments > Client > Sign > Pixel Consistent`

Turn on Texture Pack Support: provides help for textures not provided by this pack and attempts to make dynamic custom textures.
> (Already configured that the base vanilla textures will fit but modded can be applied as well at the small cost of some CPU usage at startup)
- `Supplementaries > Client > General > Dynamic Assets Generation Mode`
- `Amendments > Client > General > Texture Pack Support`
